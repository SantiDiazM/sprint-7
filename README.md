# Análisis de anuncios de vehículos

Esta aplicación web permite realizar un análisis exploratorio básico de un conjunto de datos de anuncios de venta de vehículos.

La aplicación fue desarrollada con Python y Streamlit. Permite visualizar:

- Un histograma con la distribución del kilometraje de los vehiculos.
- Un diagrama de dispersión que muestra la relación entre el kilometraje y el precio.
- Casillas de verificación para seleccionar los gráficos que se desean mostrar.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly express
- Streamlit
